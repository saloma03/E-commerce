## Project Description
This repository contains the **E-Commerce web app frontend**. The application provides product listings, product details pages, shopping cart functionality, and an interactive, responsive user experience.

The project is deployed on Netlify, and the login page can be accessed through the link above.

## Local Setup

1. Clone the repository:

```bash
git clone https://github.com/saloma03/E-commerce.git
cd E-commerce
```

2. Install dependencies:

```bash
npm install
# or
yarn
```

3. Run the development server:

```bash
npm run dev
# or
npm run serve
```

4. Build for production:

```bash
npm run build
```

## Deployment Notes
- The deployed version uses **Netlify** (or another static hosting service). Make sure your `build` output (e.g., `dist/`) is correctly configured.
- If environment variables are required (e.g., `API_BASE_URL`, `NODE_ENV`), set them up in the Netlify dashboard under Environment Variables.
